{{ staff("How it works") }}

In 2017 I built the Dance Judge twice: once in Node, and once, to learn Flask, in Python. Both asked Spotify how danceable a song was, and Spotify has since closed that door to hobby apps. The Node one became a page on my site that does the listening in your browser. This is the Flask one, finished at last, and here the server does the listening.

When you pick a song, the server downloads Apple’s 30-second preview and decodes it. The judge measures how much new sound arrives in each 12-millisecond slice, then looks for the delay at which that pattern best repeats: that’s the beat, and how cleanly it repeats is how strong the beat is. It also tallies the notes it hears against the 24 major and minor key profiles, and checks how loud, bright, and percussive the clip is.

A model fit to Spotify’s archived scores for 295 songs turns those measurements into Spotify’s old 0-to-1 scales. On songs it wasn’t fit to, the judge reaches the same verdict Spotify’s number would about three times in five, and comes within one verdict nearly every time. It only hears thirty seconds, though, and it has opinions of its own. The verdicts are the same ones from 2017.

The listening code is a NumPy port of the browser version’s, tested to take the same measurements from the same samples. To have a whole song judged from a file of your own, use the browser version, which never uploads it.
